# 深度作为输出训练 VLA：初步文献调研

调研日期：2026-09-22。范围：语言条件机器人操作策略，以深度图、深度 token 或未来几何为预测目标。优先使用作者论文、项目页和官方代码；未运行复现。本文是针对研究思路的定向调研，不是系统综述，也不构成“没有遗漏先例”的保证。

## 1. 结论

**已有直接相关工作，不能将“VLA 预测深度以辅助动作学习”本身作为首次贡献。** PAD-Depth 联合生成深度和动作，DreamVLA 预测未来深度，DepthVLA 保留深度预测损失，MolmoAct 生成深度 token 后再生成动作，GAM 将未来几何预测与动作解码结合。来源见第 3 节。

**尚不能从本次核实的论文中确认：所有模块随机初始化、只以深度作为显式中间接口、最终完成语言条件操作的方案已被充分验证。** 这只是本次检索的证据边界，不能据此声称该组合没有先例。

## 2. 先把研究问题拆开

### 深度“输出”的四种定义

| 定义 | 可检验的模型形式 | 需要区分的内容 |
|---|---|---|
| 当前深度辅助监督 | RGB + 语言 + 状态 → 动作，以及当前深度 | 几何感知，不等于预测动作后果 |
| 未来深度辅助监督 | 历史观测 + 语言 → 动作，以及未来深度 | 是否真的帮助控制，而不只是多一个 loss |
| 深度 token 推理步骤 | RGB + 语言 → 深度 token → 规划/动作 | 可能仍有 RGB 到动作的旁路，不一定是严格瓶颈 |
| 深度作为计划接口 | RGB + 语言 → 目标/未来深度 → 控制器 | 必须说明深度怎样变成可执行动作 |

这四种是本文用于比较的方法分类，不意味着每篇论文都采用这些术语。如果系统最终只输出深度图而没有控制器，应先把它界定为几何预测/规划模块，而不是完整机器人控制系统。

### “从零训练”的三种定义

1. **全参数随机初始化**：视觉、语言、策略、深度模块均不加载预训练权重。
2. **新策略主干从零**：允许预训练视觉/语言编码器，但策略或动作模块随机初始化。
3. **无机器人动作预训练**：不加载现成 VLA，但允许 VLM、几何模型的预训练权重。

三者不可混写。尤其 DepthVLA 表格中的 `Pretrained ×` 指没有额外机器人动作数据预训练，不是没有任何预训练模型。[DepthVLA §IV-B](https://arxiv.org/html/2510.13375v1#S4.SS2)

## 3. 最直接相关的论文

### 3.1 PAD / PAD-Depth — Prediction with Action: Visual Policy Learning via Joint Denoising Process

- 时间：NeurIPS 2024；arXiv 首稿 2024-11-27。
- 方法：联合去噪生成未来 RGB、动作；PAD-Depth 扩展还包括深度，且当前深度也作为条件。
- 关系：是“深度作为输出”的直接先例，但不是纯 RGB 输入下只增加深度监督的干净对照，也不是先解码深度再产生动作的串行结构。
- 初始化：论文 §3.3 明确从 ImageNet 预训练 DiT 初始化，另用预训练 VAE/CLIP，并有机器人数据预训练阶段；论文主实验不是随机策略主干或全模块从零的正例。
- [论文](https://arxiv.org/abs/2411.18179)；[全文](https://arxiv.org/html/2411.18179v1)；[官方代码](https://github.com/Robert-gyj/Prediction_with_Action)。更详细的源码核查见同目录 `depth-output-direct-works.md`。

### 3.2 DreamVLA — A Vision-Language-Action Model Dreamed with Comprehensive World Knowledge

- 时间：arXiv 2025-07-06；NeurIPS 2025。
- 方法：从 RGB 观测预测未来动态区域、深度和语义，由相应潜表示支持动作生成。
- 关系：如果设想是“增加未来深度输出以训练更好的动作表示”，这是必须比较的直接工作。推理可以跳过预测头，因此不是依赖显式深度图的严格串行控制接口。
- 初始化：公开代码允许 GPT-style 主干随机初始化，论文冻结视觉/文本编码器，并采用机器人数据预训练再下游训练的流程。不能将默认构造参数等同于所有论文实验的初始化设定。
- [论文](https://arxiv.org/abs/2507.04447)；[全文 v3](https://arxiv.org/html/2507.04447v3)；[项目](https://zhangwenyao1.github.io/DreamVLA/)；[官方代码](https://github.com/Zhangwenyao1/DreamVLA)。详细证据见配套笔记。

### 3.3 3D Foresight / 3DDA

- 版本提示：arXiv 2502.10028 首稿发布于 2025-02-14；明确的当前/未来深度任务已在 2026-02-02 修订版中核实，不能把现版方法全部倒推到 2025 初稿。
- 方法：RGB 输入，使用当前深度和未来 RGB-D 等几何辅助预测；动作读取专门的 query 表示。
- 关系：与当前/未来深度作为训练监督直接相关；辅助解码头可在部署时删除。
- 初始化：有 scratch 消融，但仍涉及预训练 MAE/CLIP，不能据此称全系统随机初始化。
- [版本记录](https://arxiv.org/abs/2502.10028)；[核查全文 v4](https://arxiv.org/html/2502.10028v4)；[官方代码](https://github.com/Stardust-hyx/3D-Foresight)。版本与初始化核查详见配套笔记。

### 3.4 MolmoAct — Action Reasoning Models that can Reason in Space

- 时间：arXiv 2025-08-11。
- 方法：依次生成深度感知 token、可编辑的轨迹推理表示、低层动作。深度 token 主要表达当前观测的几何，不能自动归类为未来深度视频生成。
- 关系：如果设想是“先输出深度，再据此决定动作”，比单纯多任务 loss 更接近。但仍须区别结构化生成顺序与信息必须经过深度的严格瓶颈。
- 初始化：视觉和语言组件加载已有 checkpoint，再按 Molmo 的流程做视觉语言对齐及机器人训练；不是所有模块随机初始化，也不能简单说只是微调现成 Molmo checkpoint。官方发布权重、训练代码和数据。
- [论文](https://arxiv.org/abs/2508.07917)；[全文](https://arxiv.org/html/2508.07917v1)；[作者说明](https://allenai.org/blog/molmoact)；[官方代码](https://github.com/allenai/molmoact)。
- 2026-05-05 已有 **MolmoAct2**；官方仓库包含 `MolmoAct2-Think`，明确保留行动前深度 token 推理路线。不要只调研第一代。[官方发布](https://allenai.org/blog/molmoact2)；[第二代代码与模型说明](https://github.com/allenai/molmoact2)。

### 3.5 DepthVLA — Enhancing Vision-Language-Action Models with Depth-Aware Spatial Reasoning

- 时间：2025-10-15。
- 方法：VLM、深度 expert、动作 expert 构成多专家模型；动作读取深度 expert 的中间特征，训练目标保留深度预测损失与动作 flow-matching 损失。
- 深度目标：当前观测的深度，而非未来深度。不是“只有深度输入，没有深度输出”。
- 初始化：使用 PaliGemma-3B、Depth Anything V2 初始化的视觉编码器及额外几何预训练；部分实验无额外动作数据预训练，不等于全参数从零。
- 与研究问题最相关的消融：论文报告随机初始化深度 expert 的设置低于预训练设置，意味着“去掉几何预训练”不是已经解决的问题；具体比较仅限其论文设定。
- [论文](https://arxiv.org/abs/2510.13375)；[方法、初始化与消融](https://arxiv.org/html/2510.13375v1)。本次未确认作者正式发布的可复现代码，勿把同名个人仓库自动认作官方实现。

### 3.6 GAM — Geometric Action Model for Robot Policy Learning

- 时间：2026-06，arXiv 2606.17046。
- 方法：在预训练几何基础模型中插入因果未来预测器，共享表示输出动作与未来深度，联合优化动作、未来特征和未来深度目标。
- 关系：不是普通 RGB 生成，而是明确使用未来几何学习策略；与“用几何模型/深度输出替代视频生成路线”高度相关。
- 初始化：DA3-Giant 几何主干与冻结 T5 编码器，并有大规模机器人轨迹预训练；不是全参数从零。
- [论文](https://arxiv.org/abs/2606.17046)；[方法及训练细节](https://arxiv.org/html/2606.17046v1)。未运行复现，不把论文报告的速度视为自己设备上的保证。

## 4. 较新的邻近路线与证据边界

### Geometry-Aware Mid-Training for World-Action Models

作者项目页描述：先用无动作视频的 RGB/深度目标做视频模型中间训练，再联合预测动作、RGB、深度；推理无需深度传感器。页面还有去掉 RGB 预测目标的 depth-only 消融，注意这个词不等于完全不输入 RGB，也不等于系统只输出深度、不输出动作。

与“把深度作为生成目标而不是输入”非常接近。但截至本次访问，页面仍写 **Paper / arXiv / Code coming soon**，只能作为作者披露的工作线索，不能当成已公开完整论文或独立复现实证。

来源：[作者项目页](https://junhahyung.github.io/geometry-aware-midtraining/)。

### RynnWorld-4D

官方仓库于 2026-07 公告代码、checkpoint 和技术报告，联合生成 RGB、深度、光流；其 policy 直接利用内部潜表示，而不是每次把完整视频生成完再执行动作。仓库要求预训练 Wan2.2 基础模型，policy 还使用深度估计模块，不是全系统随机初始化。它是未来几何世界模型与控制结合的邻近工作，不能简单写成 depth-only VLA。

来源：[官方仓库、训练和模型要求](https://github.com/alibaba-damo-academy/RynnWorld-4D)。

### 深度输入路线不要混作同类证据

例如 SpatialVLA 使用估计深度形成空间表示，回答的是怎样利用输入几何；需要与“深度作为监督输出”区分。DepthVLA 的相关工作部分有这一方法定位，但若后续做实验基线，应进一步阅读 SpatialVLA 原论文，而不只依赖其他作者的概括。[DepthVLA §II-B](https://arxiv.org/html/2510.13375v1#S2.SS2)

## 5. 可以进一步检验的研究方向

以下是调研后的研究建议，不是已证实创新点。要做 novelty claim，仍需围绕最终形式补一轮定向检索。

1. **几何监督是否降低从零策略学习的数据需求？** 固定参数量、数据、训练预算，比较 action-only、当前深度、未来深度、二者联合，以及预训练/随机初始化策略。
2. **任务相关深度是否优于整幅深度？** 重点监督物体、夹爪及交互区域，而非让大面积静态背景主导目标；需要 ablation，不能先认定会更好。
3. **深度是否是真正被动作利用的中间接口？** 人为编辑/干预预测深度，测试动作是否按几何变化；对比无 RGB 旁路、保留旁路、只有辅助 loss。
4. **无动作视频几何学习能否迁移到少量机器人示范？** 与直接微调、RGB-only 预测、现有几何中间训练路线比较，而非仅展示深度图看起来合理。

最小实验建议：同一轻量策略、同一任务数据，设置 A 动作损失、B 加当前深度、C 加未来深度、D 二者联合。再分别在“策略随机初始化”和“允许预训练策略”的条件下比较。首轮不要同时更换主干、数据集、输出表示和训练日程，否则难以归因。

建议指标：任务成功率、示范数量曲线、训练预算/收敛速度、视角变化鲁棒性、推理延迟；深度误差仅作为辅助指标。若使用教师伪深度，需要另列教师模型及其预训练来源，不能将整个训练流程称作完全没有外部知识。

## 6. 阅读顺序与待澄清问题

- 当前深度作为辅助输出：DepthVLA → 3D Foresight。
- 未来深度与动作联合学习：DreamVLA → PAD-Depth → GAM。
- 先生成深度 token 再行动：MolmoAct → MolmoAct2-Think。
- 视频模型的几何预训练：Geometry-Aware Mid-Training 项目线索 → RynnWorld-4D。

下一步最重要的澄清：**你说的“深度作为输出”，是当前深度、未来目标深度，还是替代动作的深度计划？“从零”是否允许预训练视觉/语言编码器？** 这两点决定最直接的先例、可声称的贡献以及可行的实验规模。
